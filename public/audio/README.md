# Folder Musik Game (BGM)

Letakkan file lagu berformat `.mp3` atau `.wav` di folder ini dengan nama:
`bgm.mp3`

Lokasi lengkap file:
`public/audio/bgm.mp3`

Game akan secara otomatis memutar file `bgm.mp3` tersebut saat aplikasi dibuka.
Jika file ini belum ada, sistem akan otomatis menggunakan musik instrumen petualangan bawaan.
