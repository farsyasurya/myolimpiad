# Asset Icons
Tempatkan file icon game Canva di sini:
- `star.png`
- `star-empty.png`
- `lock.png`
- `level-node.png`
- `trophy.png`

Komponen `StarRating.jsx` dan `LevelNode.jsx` memisahkan icon bintang dan lock dari latar belakang sehingga jumlah bintang dinamis dan level locked/unlocked dapat diganti dengan mudah.
